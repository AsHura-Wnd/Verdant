🌱 About the Platform

Online Gardening Community Platform

A collaborative digital sanctuary built for urban plant lovers, allotment growers, and home horticulturists.

Core Pillars of Verdant

Gardening Tips & Guides

Curated, practical knowledge on cold-pressed neem sprays, organic composting, water propagation, and container soil mixes.

Plant Clinic & Q&A

Community problem diagnosis for yellowing leaves, spider mites, powdery mildew, and root rot with expert advice tags.

Personal Projects

Track indoor windowsill terrariums, balcony herb boxes, and rooftop veggie patches through planning, vegetative, and harvest stages.

Technical Architecture

Layer Technology Description
Backend Framework Java 17/26 & Spring Boot 3.1.2 REST controllers, Spring MVC, and Service layer business logic.
Persistence & Database Spring Data JPA & Embedded H2 Database Persistent file-based database (./data/gardendb) surviving application restarts with zero external setup.
Frontend Engine Thymeleaf 3 Server-rendered HTML5 templates with responsive Bootstrap 5 and custom garden aesthetic styles.
Validation Jakarta Bean Validation Robust input validation on all forms with user-friendly error banners.
REST API Spring Web MVC (/api/*) JSON endpoints available for Tips, Discussions, Projects, and Stats.
